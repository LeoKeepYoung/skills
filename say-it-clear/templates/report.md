# 会话复盘模板

只输出有内容的可选章节。不要显示方括号占位符、内部分类代码或分析过程。

```markdown
# 会话复盘

## 分析范围

- **分析对象：** [用户或说话人]
- **覆盖范围：** [起止消息、轮次或用户提供的材料]
- **材料限制：** [截断、附件不可读、说话人不明等；没有则写“未发现影响分析的缺口”]

## 思考上的问题

### [用具体差距命名，不使用人格标签]

**对话证据**

> [必要的短原话]

[需要时补充相邻轮次发生了什么。]

**问题在哪里**

[说明前提、概念、理解、推理或判断标准的缺口，以及证据来自原句还是后续验证。]

**造成的影响**

[说明对理解、回答、判断、决策或会话推进的具体影响。]

**修复方法**

[说明下次应增加的思考步骤。]

**更完整的思考或回答示例**

> [保留原意并补齐思考链的示范]

## 表达上的问题

### [用具体表达差距命名]

**对话证据**

> [必要的短原话]

**可由上下文支持的原意**

[只有证据足够时重建原意；否则说明存在的多个解释。]

**表达差距及影响**

[指出遗漏、模糊、错排、冗余、衔接或措辞失准，以及读者可能怎样理解。]

**改进方法**

[说明下次可采用的表达动作。]

**更清楚的表达**

> [保留事实、立场、条件、礼貌和不确定性的完整改写]

**术语说明**

[仅在涉及专业术语、词义边界或多个候选说法时出现。]

## 下次对话可直接采用的方法

- [从本次真实问题归纳的一项动作]
- [可选第二项]
- [可选第三项]

## 未纳入结论的疑点

- [重要但证据不足的迹象、两种解释，以及还需要什么信息]
```

## 无问题时

如果没有候选问题通过证据门槛，使用：

```markdown
# 会话复盘

## 分析范围

- **分析对象：** [用户或说话人]
- **覆盖范围：** [实际范围]
- **材料限制：** [实际限制]

## 结论

本次材料中未发现有充分证据、且实际影响理解或会话推进的思考与表达问题。短句、省略或口语化表达均能由上下文明确恢复，因此不作为问题报告。
```

不要为无问题结果补充通用建议。
